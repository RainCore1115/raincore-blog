<a name="鹿功能说明"></a>

## 🦌 鹿功能说明

### 基础签到

| 命令                   | 说明            |
| -------------------- | ------------- |
| `🦌` 或 `鹿`           | 进行今日签到（有失败概率） |
| `补🦌[日期]` 或 `补鹿[日期]` | 补签指定日期        |
| `戒🦌[日期]` 或 `戒鹿[日期]` | 减少指定日期的签到次数   |
| `看🦌` 或 `看鹿`         | 查看自己的签到面板     |
| `看🦌 @某人`            | 查看他人的签到面板     |

### 🎯 倍数签到

| 命令                 | 说明               |
| ------------------ | ---------------- |
| `🦌×n` 或 `鹿×n`     | 消耗 n 个杯面，尝试倍数签到  |
| `解除鹿失败` 或 `解除🦌失败` | 消耗 10 杯面解除当日失败锁定 |

**注意**：倍数签到有失败风险，失败仅扣除杯面且当天无法再签到。

### 🤝 鹿友系统

| 命令            | 说明                    |
| ------------- | --------------------- |
| `添加鹿友 @某人`    | 添加鹿友（对方才能帮你签到）        |
| `添加鹿友 all`    | 开启全员鹿友模式，所有人都可以帮你签到   |
| `绝交鹿友 @某人`    | 删除鹿友                  |
| `绝交鹿友 all`    | 关闭全员鹿友模式              |
| `我的鹿友`        | 查看我的鹿友列表及全员模式状态       |
| `帮鹿 @某人`      | 帮鹿友签到一次               |
| `帮鹿×n @某人`    | 消耗 n 杯面帮鹿友倍数签到        |

**注意**：
- 只有被添加为鹿友的人才能帮你签到
- 开启全员鹿友模式后，所有人都可以帮你签到，无需单独添加

### 🏆 排行榜

| 命令             | 说明              |
| -------------- | --------------- |
| `🦌榜` 或 `鹿榜`   | 查看本群签到次数排行榜（降序） |
| `戒🦌榜` 或 `戒鹿榜` | 查看本群签到次数排行榜（升序） |

排行榜每月重置一次。

<a name="杯面返还机制"></a>

## 💰 杯面返还机制

当鹿成功完成指定任务时，系统会按照预设倍数自动返还相应数量的杯面。

### 返还规则

| 条件       | 返还倍数 | 说明           |
| -------- | ---- | ------------ |
| 普通成功     | 1倍   | 返还与投入数量相等的杯面 |
| `鹿×3` 成功 | 3倍   | 返还投入数量3倍的杯面  |

### 示例

- 发送 `鹿×3` 成功：投入3杯面 → 返还9杯面（3×3）
- 发送 `鹿×5` 成功：投入5杯面 → 返还5杯面（5×1）
- 发送 `帮鹿×3 @某人` 成功：投入3杯面 → 返还9杯面（3×3）

### 返还管理命令

| 命令       | 说明                 |
| -------- | ------------------ |
| `我的返还日志` | 查看最近10条返还记录        |
| `我的返还统计` | 查看返还统计信息（总次数、总收益等） |

<a name="kkb互动系统"></a>

## 💕 KKB互动系统

KKB（扣扣B）是一个趣味互动系统，消耗杯面对群友进行"注入生命因子"操作。

> 💡 **提示**：所有 `#kkb` 指令均可使用 `#ccb` 作为别名，例如 `#ccb @目标`、`#ccbinfo` 等。

### 基础操作

| 命令               | 说明                  |
| ---------------- | ------------------- |
| `#kkb @目标` / `#ccb @目标` | 对目标进行 扣扣B 操作（需消耗杯面） |
| `#kkb` / `#ccb`       | 随机选择一位幸运群友进行 扣扣B   |
| `#kkbinfo [@目标]` / `#ccbinfo [@目标]` | 查询 扣扣B 信息（不填则查询自己）  |

### 保护模式

| 命令               | 说明             |
| ---------------- | -------------- |
| `#kkb --on` / `#ccb --on`      | 关闭保护模式，允许被 扣扣B |
| `#kkb --off` / `#ccb --off`     | 开启保护模式，禁止被 扣扣B |
| `#kkb --on @用户` / `#ccb --on @用户`  | 允许特定用户对你 扣扣B   |
| `#kkb --off @用户` / `#ccb --off @用户` | 禁止特定用户对你 KKB   |

### 排行榜

| 命令          | 说明             |
| ----------- | -------------- |
| `#kkbtop` / `#ccbtop`   | 被次数排行榜 TOP5    |
| `#kkbvol` / `#ccbvol`   | 被注入量排行榜 TOP5   |
| `#kkbmax` / `#ccbmax`   | 单次最大注入排行榜 TOP5 |
| `#kkbcharm` / `#ccbcharm` | 魅力榜 TOP5       |

### 游戏机制

- **消耗杯面**：每次 KKB 需要消耗一定数量的杯面
- **炸膛风险**：有概率触发炸膛，需要支付修理费才能继续
- **暴击机制**：有概率触发暴击，注入量翻倍
- **冷却时间**：切换保护状态有冷却时间限制

## 👆 戳一戳榜（Poke-plugin）

自动记录群成员互相「戳一戳」的行为，支持今日 / 总榜、戳人 / 被戳多个维度，榜单支持文本与图片两种输出。

### 排行榜

| 命令 | 说明 |
| --- | --- |
| `戳戳榜` / `poke榜` | 本群戳人总榜 |
| `今日戳戳榜` / `今日poke榜` | 本群今日戳人榜 |
| `戳戳总榜` / `poke总榜` | 全局戳人总榜 |
| `被戳戳榜` / `被poke榜` | 本群被戳总榜 |
| `今日被戳戳榜` / `今日被poke榜` | 本群今日被戳榜 |
| `被戳戳总榜` / `被poke总榜` | 全局被戳总榜 |

### 查询与帮助

| 命令 | 说明 |
| --- | --- |
| `查询戳戳 [@某人]` / `查询poke [@某人]` | 查询某人（不填则查自己）的戳戳统计 |
| `戳戳帮助` / `poke帮助` | 查看插件帮助 |

> 💡 榜单命令末尾可直接跟数字调整条数，例如 `戳戳榜5`、`今日被戳戳榜10`。数据存于 Redis，会按配置定期清理。

<a name="语音触发"></a>

## 🔊 语音触发（audio-trigger）

聊天里出现触发词时，机器人自动把对应音频以**语音**形式发出来。每个条目有独立冷却（默认 3 分钟），且**群友可以自助添加**，不用改配置、不用重启。

### 内置触发表

| 触发词 | 内容 | 说明 |
| --- | --- | --- |
| `大音晶`、`x x xxx` | 大音晶 | 约 168 秒（长语音） |
| `大早上` | 大早上 | 3 秒 |
| `cc` | cc | 词边界正则 `\bcc\b`，约 103 秒 |
| `家豪`、`嘉豪`、`褪色`、`faded`、`你在哪` | 家豪 | 约 181 秒 |
| `冰`、`🧊` | 冰 | 子串匹配 |
| `唉`、`叹气`、`叹` | 叹气 | 1.5 秒 |
| `bee`、`bees`、`小蜜蜂`、`electric hornet` | electric-hornet | 冷却 5 秒 |

> 💡 除内置条目外，群友用 `#添加语音` 加出来的条目请以 `#语音列表` 的实际输出为准。

### 命令一览

| 命令 | 谁能用 | 说明 |
| --- | --- | --- |
| `#添加语音` | 所有人（可关闭） | 引导式添加：先选范围 → 再选触发条件 → 再输触发词 → 再发音频 |
| `#修改语音 [条目名]` | 主人任意；普通用户仅限**本群的非全局条目** | 逐项修改触发词、触发条件、概率、冷却、附带文字、重录音频等 |
| `#语音列表` | 所有人 | 查看可用条目（普通用户只看本群可用的） |
| `#删除语音 <条目名>` | 主人任意；普通用户仅限**自己**在本群添加的 | 删除条目并清理自动生成的音频 |
| `#语音触发模式 [1/2]` | **仅主人** | 切换群聊全局触发条件（包含关键词 / 只有关键词） |
| `#语音关闭` / `#语音开启` | 所有人 | 关闭 / 恢复**本群**的全部语音触发 |
| `#语音关闭 全局` / `#语音开启 全局` | **仅主人** | 关闭 / 恢复**所有群**（私聊不受影响） |
| `#语音帮助` | 所有人 | 命令菜单（也认 `#语音菜单` / `#语音命令` / `#语音用法`） |
| 回复「取消」 | 会话中 | 中止当前添加 / 修改流程 |

新增、修改、删除都是**立即生效**的：插件会在运行期重编译匹配规则，**不需要重启**。

> ⚠️ `冰` 是**子串**匹配，`冰淇淋`、`冰箱` 也会触发；`cc` 使用 `\bcc\b` 词边界，避免 `access`、`success` 之类的单词误触发。

### 添加流程示例

```
你：#添加语音
Bot：请选择生效范围，回复数字：1 = 全局，2 = 仅本群

你：2
Bot：请选择触发条件，回复数字：
     1 = 包含即发（发言里出现这个词就发，推荐）
     2 = 只有单独发才发（必须整条发言就是触发词）

你：2
Bot：请输入触发关键词。多个词用空格或逗号分隔。

你：晚安 睡觉了
Bot：现在请发送要播放的语音或音频文件。

你：[发一条语音]
Bot：✅ 已添加语音触发  条目名：晚安  范围：仅群 888888  音频：2.4s
```

**权限说明**

- **主人**：群里可选全局或仅本群；私聊添加只能是全局。
- **普通用户**：不会被询问范围，默认就是**仅本群**（私聊会被拒绝），且只能删除自己在本群添加的条目。
- 可通过 `allowUserAdd: false` 禁止普通用户添加。

### 触发条件：包含即发 / 只有单独发才发

| 群里发言 | `包含即发`（默认） | `只有单独发才发` |
| --- | --- | --- |
| `家豪` | ✅ 发 | ✅ 发 |
| ` 家豪！ ` | ✅ 发 | ✅ 发（首尾空白标点忽略） |
| `家豪在家吗` | ✅ 发 | ❌ 不发 |
| `a cc b` | ✅ 发 | ❌ 不发（正则也要整条命中） |

- 优先级：**条目自己配了就以条目为准** → 否则群聊跟随全局开关 `groupStrictMatch` → **私聊恒为「包含即发」**（方便先私下试词）。
- 主人可用 `#语音触发模式` 一步切换全局模式，改完立即写回配置并热重载。
- emoji 触发词不会被当标点吃掉，`🧊` 照样能用。

### 触发概率与冷却

| 机制 | 说明 |
| --- | --- |
| 触发概率 | 条目可设 `probability`，`30` / `30%` / `0.3` 三种写法等价；`1` / `100` / `"100%"` 为必定触发，`0` 为永不触发 |
| 掷骰时机 | **每次命中都独立掷骰**，在冷却检查之后、发送之前；没中就静默跳过，不发送也不提示 |
| 没中不消耗冷却 | 冷却只在实际发出语音后才开始计时，避免低概率条目白白吃掉整段冷却 |
| 冷却范围 | `session` 同群/同人（默认）、`user` 跨群同一人、`global` 全局；`0` 表示不限制 |
| 按条目独立 | 「大早上」的冷却不影响「大音晶」 |
| 共用关键词 | 关键词重复的条目会**并成同一个冷却组**，组内共享冷却并取组内最大值 |

### 多条目同时命中

一条消息命中多个条目时，默认**随机只发一个**（`multiMatch: "random"`）；想「全部依次发」就设为 `"all"`。随机只在**当前未被冷却**的条目里挑，且只消耗被选中条目的冷却——若命中的条目全在冷却中，则不发。

### 补充说明

- 触发词命中即发，**不做命令前缀限制**（`#` 开头也会触发）。
- 交互式添加的音频上限 20MB（转码后 silk 上限 7MB），超限会拒绝并提示。
- 单条配置写错（如正则非法）只会跳过该条，其余条目照常工作，错误写入日志。
- 发送失败时冷却**保留**，避免持续重试刷日志；长语音（如 168 秒的大音晶）偶尔会被服务端拒收。

群友共享课程表：导入一次，群里谁都能查「今天上什么课」「群友在上什么课」。

### 导入 / 导出

| 命令 | 说明 |
| --- | --- |
| 直接发送 **WakeUp 课程表**的分享口令 | 自动识别并导入 |
| 直接发送 **拾光课程表**导出的文件 | 自动识别并导入 |
| `导入课表` / `ct导入课表` | 手动触发导入 |
| `导出课表` | 导出当前课表（可指定「拾光」格式） |
| `确认导出课表` / `取消导出课表` | 确认或取消导出 |
| `课表插件更新` / `课表插件强制更新` | 更新插件数据 |

### 查询

| 命令 | 说明 |
| --- | --- |
| `今天课表` / `明天课表` / `后天课表` / `昨天课表` | 查看对应日期的课表 |

### 🔮 指令纠错建议（fuck）

`@机器人` 时如果指令打错了，会从**全部已注册指令**里按相似度推荐最接近的几条，不用再去翻菜单。

```
@Bot 加人
→ 找不到你想要的指令哦喵~
  你是否想要使用下面可能的指令喵？
  1. 加入（nonebot_plugin_partner_join）
```

| 规则 | 说明 |
| --- | --- |
| 触发条件 | 消息必须以 `@机器人` 开头，且 `@` 之后**只能是纯文本**（带图片 / 表情不触发） |
| 不触发 | 文本与已有指令**完全一致**时不回复，避免对正常调用刷屏 |
| 候选来源 | 遍历全部已注册 matcher：`on_command` 命令与别名、`on_keyword` 关键字、`on_startswith` 前缀、`on_regex` 正则字面量、Alconna 命令名 |
| 排序 | 长度比门槛 → Levenshtein 相似度（0.82）+ 公共前缀奖励（0.18），默认阈值 `0.42`，返回前 3 条 |
| 中文优化 | CJK 字符按 2 字符宽度计入门槛，让「加入」这类两字中文指令也能参与纠错 |

> 注意：像 `arcaeabot` 那样不使用规则、在 handler 内部自己判断文本的插件无法被自动提取。
